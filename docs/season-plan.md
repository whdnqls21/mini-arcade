# 뇌지컬 리그 — 시즌제 & 보상 아이디어 (구상)

> 상태: 운영 규칙은 **2026-07-28 논의로 확정**(아래 "확정된 운영안"). **1·2단계 구현·배포 완료
> (2026-07-29)** — 아래 "구현 현황" 참고. 남은 건 **3단계(밸런스 DB화)**와 선택 항목(닉네임 네온·자동 종료).
> 프로필 꾸미기(아이콘·칭호·소개)는 시즌제와 별개로 **먼저 구현·배포됨**(아래 "이미 구현된 것").

## 이미 구현된 것 (2026-07-27)

시즌제와 별개로 프로필 꾸미기를 먼저 넣었다. 시즌 보상은 이 위에 쌓는다.

- **닉네임 아이콘** — 기본(자유 선택 18종) + 획득(게임 1위·전종목 GOAT·누적 100판 등, 조건
  충족 시 앱 로드에서 **자동 영구 획득**). 카탈로그·조건은 `src/lib/icons.ts` 한 곳.
  저장: `ma_accounts.icon`(장착) + `ma_account_icons`(영구 획득). 판정: `state.ts` `eligibleIcons`.
- **아이콘 등급 테두리** — 기본=브론즈, 획득=은색, **시즌 보상=금색**(색·타입만 준비, 아직 미사용).
  `TIER_RING` in `src/lib/icons.ts`, 렌더는 `IconBadge`.
- **칭호** — 보유한 획득 아이콘의 이름을 칭호로 선택(아이콘 장착과 별개). `ma_accounts.title`, 렌더 `TitleTag`.
- **한 줄 소개** — 30자. `ma_accounts.bio`.
- 이름 렌더 지점(내정보·리더보드·게시판)에 아이콘 코인 + 칭호 태그로 노출. 장착/설정은
  `POST /api/auth/profile`(setIcon/setTitle/setBio).
- **다음 후보(시즌 전에):** "남의 프로필 보기"(이름 탭 → 그 사람 프로필: 아이콘·칭호·순위·보유 목록).

## 왜 시즌제인가

게임을 계속 추가할 계획이라, 언젠가 기록이 굳어 후반부가 지루해진다.
시즌으로 판을 리셋하고 밸런스를 조정하면 그게 풀린다. 반대로 밸런스를
바꾸면 이전 기록과 비교가 무의미해지는데, 시즌이 기록을 끊어주므로 두
아이디어가 서로를 필요로 한다.

## 확정된 운영안 (2026-07-28 논의)

인원이 **7~10명**으로 늘어난 걸 전제로 확정한 규칙. 착수 시 이대로 간다.

### 시즌 구성 · 로테이션
- **점수 게임 10종 중 시즌당 5개(기본)를 "이번 시즌 종목"으로 로테이션.** 5면 전 종목이 두 시즌에
  한 바퀴 돌고 F1 포인트 층도 두꺼워진다. 관리자 수동 선정이라 **4~6개 사이에서 유동적**으로 정해도 된다.
- **종목 선정은 관리자 수동.** 관리자가 매 시즌 직접 고른다(테마·인기 반영 가능). 자동 순환("관리자가
  안 고르면 최근 안 나온 게임으로 자동 채움")은 나중에 얹을 수 있게 여지만 둔다.
- **선정 외 게임도 그대로 플레이 가능.** 비시즌 게임은 목록에서 계속 열리되 기록이 **시즌 점수·MVP에는
  안 들어가고**, **전체 기간(올타임) 리더보드**를 보여준다("자유 종목"). 시즌 종목은 현재 시즌 리더보드.
- **캐치마인드는 시즌·MVP에서 제외.** 점수(high/low/time) 순위가 없는 비동기 소셜 게임이라
  F1 포인트로 환산할 대상이 아니다. 시즌과 무관하게 **상시 오픈되는 소셜 모드**로 둔다.
  (나중에 "인기 그림 투표" 같은 별도 부상은 얹되, MVP 점수엔 안 넣는다.)
- 로테이션에 새로 넣는 시즌에만 그 게임 파라미터를 손보면 된다(매 시즌 전부 만질 필요 없음).

### 기간 · 관리자 제어
- **15일 시즌 → 2~3일 정비(오프시즌) → 다음 시즌**이 기본 리듬.
- **관리자가 기간을 설정한다.** 시즌 생성 시 시작일·종료일을 지정(종료일 기본 +15일, 관리자가 변경 가능).
- **관리자가 언제든 종료할 수 있다.** 활성 시즌을 '지금 종료'하면 종료일 전이어도 즉시 스냅샷
  (명예의 전당 반영) + 오프시즌 진입. 즉 마감은 **종료일 도래 OR 관리자 수동 종료** 중 먼저 오는 쪽.
- 정비 기간에 하는 것: 결과 발표(MVP·종목별 1등 스냅샷 → 명예의 전당 갱신, 축하 배너),
  다음 시즌 로테이션 종목 밸런스 조정, 다음 시즌 예고.
- **오프시즌 동안은 직전 시즌 최종 결과를 "동결" 표시**("시즌 종료·결과 확정" + 새 시즌 카운트다운).
  게임은 플레이 가능하되 기록은 다음 시즌으로 넘어가지 않는다(연습용).
- 정비 기간이 있어 마감·오픈이 붙어있지 않으니, 크론 없는 지연 스냅샷과 궁합이 좋다.

### MVP 산정 — F1식 포인트
- **1등 10 / 2등 6 / 3등 4 / 4등 3 / 5등 2 / 나머지 1**, 종목 합산 최고점이 시즌 MVP.
  (7~10명이라 순위 층이 두꺼워 변별력·실시간 레이스 표시에 F1식이 유리.)
- **최소 참가 자격선은 두지 않는다.** 미참가 종목은 0점이라 시스템이 스스로 규제한다
  (안 한 만큼 총점이 깎임 = 자연 페널티). 규칙도 한 줄 줄어든다.
- 엣지 케이스: 참여율이 바닥인 시즌에 1~2종목만 한 사람이 MVP 먹을 수 있으나,
  7~10명이면 거의 안 생긴다. 실제로 겪으면 그때 손본다.

### 보상 (전부 무료·기록 기반, 트로피를 여러 갈래로)
소규모일수록 "내가 딸 수 있는 트로피"가 여러 갈래여야 다들 계속 접속한다.
- **종합 MVP** — "시즌N MVP" 칭호 + 그 시즌 한정 금테 아이콘 + 닉네임 네온.
- **종합 2·3위** — 반짝이/그라데이션 닉네임 효과(네온보다 약하게 차등).
- **종목별 1등** — 시즌 한정 아이콘(기존 게임별 1등 `earned` 아이콘의 시즌 버전).
- **명예의 전당** — MVP·종목별 1등을 이름 스냅샷 문자열로 영구 박제. 역대 시즌 아카이브.
- 구현 순서: **① 칭호+금테 → ② 반짝이/네온 → ③ 명예의 전당**(스냅샷만 쌓아두면 화면은 나중에).

### 인프라 재사용 메모
- 금테 아이콘: `src/lib/icons.ts` 의 `season` 등급(금색 `#f4c64e`)이 이미 준비돼 있어
  카탈로그에 `tier: "season"` 항목만 추가하면 바로 금테로 뜬다.
- 정비/예고 배너: 기존 밸런스 조정 안내 배너·모달 컴포넌트를 그대로 재활용한다.

## 아직 안 정한 것 (착수 전 확인)

- **직전 시즌 MVP 도전 구도** — 새 시즌 리더보드 상단에 지난 MVP를 왕관 달아 고정 노출할지.
- **닉네임 네온/반짝이의 구체 디자인**과 2·3위 차등 수위.
- **종목별 1등 시즌 아이콘 카탈로그** — 어떤 이모지·이름으로 줄지.
- **게임 파라미터 DB화 범위** — 어느 상수까지 시즌 설정으로 뺄지(`logic.ts` 의 `COLS`/`ROWS`/`TIME_LIMIT_MS` 등).

## 설계 시 함정 (미리 파악)

- **이름은 스냅샷으로 저장.** 사용자가 이름을 바꿀 수 있으므로(기능 있음),
  시즌 결과를 계정 참조로만 저장하면 과거 명예의 전당 이름이 소급 변경되거나
  계정 삭제 시 사라진다. 종료 시점 이름을 문자열로 박아둘 것.
- **리더보드를 시즌 범위로 축소.** `src/lib/state.ts` 의 `myBest`/리더보드가
  전 기간 기준이라, 시즌 도입 시 전부 "현재 시즌 내"로 좁혀야 한다.
  게임 화면의 "베스트" 표시까지 연쇄된다.
- **시즌 전환은 크론 없이 지연 처리.** 상태 조회 시 종료일 지난 활성 시즌이
  있으면 그 자리에서 스냅샷하고 다음 시즌을 연다.
- **게임 파라미터를 DB로.** 밸런스가 코드 상수(`logic.ts` 의 `COLS`/`ROWS`/
  `TIME_LIMIT_MS` 등)라, 시즌별 조정을 하려면 DB 설정으로 빼고 `GamePlayProps`
  에 config 를 넘겨야 한다.

## 구현 현황

### 1단계 — 기반 ✅ (2026-07-29, `main-aeupwd`)

DB 마이그레이션은 운영 Supabase 에서 실행 완료. 앱은 마이그레이션 전에도 안 깨지게
(테이블/뷰 없으면 활성 시즌 null → 전 게임 올타임) 폴백을 넣어 뒀다.

- **DB**: `ma_seasons`(num·name·games[]·starts_at·ends_at·status·closed_at, 활성 시즌 1개
  부분 유니크 인덱스) + `ma_scores.season_id` + `ma_scores_agg_season` 뷰. `supabase/schema.sql`
  본문과 하단 증분 SQL 주석에 반영.
- **기록 부착**: `api/games/record` 가 저장 시 활성 시즌 종목이면 `season_id` 부착
  (비시즌 게임·오프시즌은 미부착 = 자유 종목).
- **리더보드 축소**: `src/lib/state.ts` 가 시즌 종목은 `fetchSeasonAgg`(현재 시즌 범위), 비시즌은
  올타임. `AppState.season`·`GameView.inSeason` 노출. 게임 화면 '베스트'까지 연쇄됨.
- **UI**: 메인 시즌 배너(시즌명·D-day·종목) + 게임 카드 '시즌' 뱃지. 관리자 **시즌 탭**에서
  시즌 시작(종목 선택+기간)·지금 종료, 역대 시즌 목록. `src/lib/season.ts` = `fetchActiveSeason`.

**1단계에서 일부러 안 한 것(2단계로 넘김):**
- **지연 전환·자동 종료 안 함.** 예정 종료일(ends_at)이 지나도 관리자가 '지금 종료'를 누를 때까지
  활성 유지. 자동 종료는 스냅샷과 한 세트라 2단계에서 같이 붙인다(`fetchActiveSeason` 상단 NOTE).
- **스냅샷·명예의 전당·MVP 집계 없음.** 시즌 종료는 status='closed' 로 닫기만 한다
  (`seasonEnd` 액션 NOTE). 종료된 시즌의 기록은 `season_id` 로 남아 있어 2단계에서 스냅샷 가능.
- **오프시즌 '동결 표시' 없음.** 활성 시즌 없으면 올타임으로 보인다(동결 화면은 스냅샷 이후).
- **획득 아이콘(게임 1위·GOAT 등)은 여전히 올타임 기준.** 시즌 순위와 별개(경력 업적). 2단계에서
  시즌 보상과 관계를 정리.

### 2단계 — 마감/보상 ✅ (2026-07-29, `main-aeupwd`)

`ma_season_results` 마이그레이션은 운영 Supabase 에서 실행 필요(아래 안내). 앱은 결과 테이블이
없으면 명예의 전당을 빈 채로 두고, 시즌 종료 시엔 스냅샷 저장 실패를 감지해 **닫지 않고 안내**한다.

- **DB**: `ma_season_results`(mvp·champion, 시즌명·게임명·정렬방식·이름·아이콘을 **종료 시점 스냅샷**으로).
  `supabase/schema.sql` 본문 + 하단 증분 SQL 주석.
- **스냅샷 계산**: `src/lib/season.ts` `computeSeasonSnapshot` — 솔로·비활성 제외, 종목별 1등(champion) +
  F1 포인트(1등10·2등6·3등4·4등3·5등2·나머지1) 합산 최고점 = MVP(동점 시 1등 개수 우선).
- **종료 연결**: `api/admin/action` `seasonEnd` 이 스냅샷 저장 → **MVP 에게 `season_mvp`(금테) 지급** →
  시즌 닫기 순. (결과 저장 실패 시 종료 취소 + 마이그레이션 안내로 유실 방지)
- **보상 아이콘**: `src/lib/icons.ts` 에 `season_mvp`(🏆, tier `season`=금테) 추가. 조건 자동판정이 아니라
  종료 시 직접 지급. `profile route` 가 season 티어를 소유검증(장착)·칭호 허용하도록 수정.
  장착 UI(`IconPicker`)·칭호 UI(`ProfileExtras`)에 '시즌 보상' 노출.
- **명예의 전당**: `state.hall`(`fetchHall`) + `순위` 페이지 상단 `HallOfFame` — 역대 시즌 MVP·종목별 1등.
  이름은 스냅샷 문자열이라 이후 개명/탈퇴에도 안 바뀐다.

**2단계에서 일부러 안 한 것(선택·나중):**
- **닉네임 네온/반짝이(2·3위 차등)** — 별도 시각 효과 시스템이 없어 미착수. 원할 때 얹는다.
- **자동 종료(지연 전환)** — 여전히 관리자 수동 종료만. 종료일 자동 마감은 이 스냅샷 로직을 크론/지연
  훅에서 호출하면 되도록 `seasonEnd` 로 캡슐화해 뒀다.
- **MVP 획득 축하 팝업** — season_mvp 는 관리자 종료 시 서버가 직접 지급(자동획득 경로가 아님)이라
  `newlyEarned` 축하에 안 잡힘. 나중에 '지급됐지만 안 본' 감지를 붙이면 됨.

### 다음(3단계) 착수 지점
로테이션 종목의 게임 파라미터(`logic.ts` 의 `COLS`/`ROWS`/`TIME_LIMIT_MS` 등)를 시즌 설정(DB)으로 빼고
`GamePlayProps` 에 config 를 넘긴다. 시즌 생성 화면에서 종목별 난이도를 조정할 수 있게.
